# bike
自行车可太难骑了！！！
提示词：
用单个 HTML 文件，内嵌 SVG 画一只鹈鹕骑自行车的 2D 动画，要有踩踏板动作、轮子转动、背景移动，风格可爱卡通，直接在浏览器打开就能播。不用外部图片，不用 JS 库，只用 SVG + CSS animation，轮子用旋转动画，腿用位移动画，鹈鹕身体有上下起伏。
